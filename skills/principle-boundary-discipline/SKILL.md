# 系统边界纪律

在数据跨越系统边界时（CLI 参数、配置文件、外部 API、网络），校验数据、收窄类型并处理错误。系统内部信任既定类型，避免重复校验和多余的空值检查。在边界将原始数据解析为领域类型，避免在公开接口上暴露传输层类型和框架类型。业务逻辑放在不依赖框架的纯函数中。调用这些函数的外壳应保持轻薄。

用两个问题判断。数据此刻正在跨越边界吗？否则，校验就是多余的。这段逻辑能提取成一个由外壳直接调用的纯函数吗？能就提取。
