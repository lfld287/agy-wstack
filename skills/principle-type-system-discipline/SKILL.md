# 类型系统纪律

让编译器拒绝不可能出现的状态、语义不匹配的基本类型值，以及未处理的变体。

- **用品牌类型区分基本类型的语义。** 如果两个参数使用同一种基本类型，但含义不同，就分别为它们定义独立的类型。在创建值时校验一次。
- **外部数据在解析前视为无类型。** JSON、RPC 载荷、CLI 参数、配置、环境变量和数据库行都应在边界交给解析函数，由它返回带类型的模型。
- **从权威模式定义派生类型。** 如果某个模式定义文件规定了数据形态，就从该文件派生类型，避免手工维护一份平行定义。

有关 TypeScript 语法，参见 **typescript-best-practices** 技能。
