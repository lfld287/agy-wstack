# 修复根因

修复故障本身，追到系统第一次做了不该做的事，或没能处理本应处理的状态的位置。那才是根因所在。

- 先复现问题。不断追问「为什么」，直到找到代码中的错误判断。卡住时，加入观测手段并读取系统的实际状态。
- 判断引发症状的状态是否合法。合法的话，就在出错位置正确处理。如果该状态本不应存在，就去找是谁产生了它。此时在出错处加检查只会掩盖缺陷。常见的掩盖手段包括加防护检查、重试、吞掉错误、强行把值限制在某个范围内，以及丢弃状态。
- 修复共同的故障模式，找出所有存在同样缺陷的位置。
- 如果关键事实要深挖才能发现，就提出一种低成本、始终开启的观测信号，让下次初看就能发现它。
