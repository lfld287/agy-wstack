# 执行无需等待人工答复

人可以异步监督，代理应继续推进。作出合理判断并执行，让人随后纠偏。代码改动可撤销、可审查，判断错误的代价通常低于停下来等答复。

- 先做，再展示结果。想问「我该做 X 吗？」时，直接做 X，并说明理由。
- 让系统具备自愈能力。发现问题时记录下来，在下一轮修复。
- 不可逆操作仍需确认，例如强制推送、删除生产数据、对外发送消息。
- 写代码、编辑笔记、拆分任务等可逆操作应直接推进。
- 产品方向由人决定，执行应持续推进。
