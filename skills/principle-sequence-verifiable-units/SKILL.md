# 按可验证单元安排工作

把工作排成各自以可检查状态收尾的小单元，当前单元通过检查后再推进。

在全面清理、迁移或连续进行同类编辑时，每个单元都从已知正常的状态出发，只做一项改动，运行检查，再继续。即使用工具执行编辑，也要逐单元运行检查。

按能证明改动有效的顺序交付。先交付会失败的测试，再交付修复。先做删减，再调整结构。先建立基线，再实施干预。每个提交都应能独立合入。
