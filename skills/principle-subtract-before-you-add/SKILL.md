# 先减后加

演进系统时，先移除复杂性，再构建。默认先做减法。

持续投入简化。保持对外接口范围不变或有所缩小，同时让设计比原来稍简单，能力更强。

- 先安排移除工作，再安排构建工作。
- 先删减再打磨。缩减到必要范围后，再投入精力提升质量。
- 按实际观察到的用法设计，避免为臆测的边缘情况设计。
- 校验器、解析器和防护检查以规范要求为限，避免凭猜测添加。
- 简化提示词，去掉重复指令和过度繁复的模板。
- 如果某个引用没有提供新内容，就删除它，避免留下占位。
