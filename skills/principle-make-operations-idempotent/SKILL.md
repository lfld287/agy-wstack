# 让操作具备幂等性

设计每个会改变状态的操作时，都要确保无论运行多少次、上次停在哪里，最终都能收敛到正确状态。

根据实际存在的状态决定每一步。上一次运行原本打算做什么，与这次如何执行无关。读取当前状态，与目标比较，只应用差异。

每次运行留下的任何东西，例如锁、临时文件、写到一半的记录或已认领的任务，都必须能在后续运行时凭证据识别为过期，即使上次停在任意位置，证据也仍然有效。先写入临时路径，再通过重命名移到目标位置。

检验时问两个问题。运行两次会怎样？上一次运行在每个可能的位置崩溃时，又会怎样？如果答案取决于之前留下的东西，就加一步状态协调，使状态恢复一致。
