### 自动推进 PR 栈（autopilot-stack）

沿用[全程自动推进](autopilot-full.md)，只推进到验证交接，禁止合并。

1. **用验证交接代替第 5 步。** 每个 PR 的当前 head 都验证通过且 CI 为绿后停止，将 PR 交给操作者。交接后须经操作者同意才能再推送。AGY `schedule` 的每次唤醒提示都要指明本文件，确保每次检查都读到禁止合并的规则。
2. **只有确实依赖另一个 PR 时才堆叠。** 这是第 3 步唯一的例外。按[开 PR](opening-a-pr.md)，把依赖的 PR 分支设为基线。第 2 步的 rebase 改为逐个对父 PR 分支执行，只有栈底 rebase 到主干。下层 PR 产生新 head 后，其上所有 PR 要重新叠放。重叠后 `git patch-id` 保持不变的 PR 可沿用验证结论。

**回复**逐个列出 PR 和验证结论，以此代替合并清单。
