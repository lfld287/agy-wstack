# 从第一性原理重新设计

将变更纳入现有设计时，避免直接在原设计上加补丁。重新设计时，把新需求视作从一开始就成立的基本前提。

- 阅读所有受影响的文件，理解现有设计。
- 问自己「如果带着这个新需求从零开始，我们会怎么做？」
- 将变更落实到每一处相关引用，包括类型、文档、示例和设计依据章节。
- 先考虑完整的重新设计，再分步交付。

这样在将变更纳入现有设计时，仍能保留未来可选方案的价值。
